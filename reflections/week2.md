## Task 3
I would create a mobile drum app that allows users to practice rhythms, create beats, and learn difficult drum patterns and i would choose the incremental development model because the app could be developed and modeled in stages. The first version could include basic drum sounds and beat creation while later version could add features like recording, tutorials, and sharing beats with other users. This would allow users to test the app early and provide feedback to help improve future versions and it would help because the exact features users would want may not be clear at the start. A possible risk could be that adding new things over time could make the app more complicated to manage and maintain. so careful planning and testing would be needed throughout developement.
