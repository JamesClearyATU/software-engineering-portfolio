Software is the programs, documents and data that all work together as one system. Engineering adds a process to how that software is made, its not just programming its also planning, designing, testing, maintaining and improving the software so that it actually works efficiently when people use it. Software engineering is about delivering a working and maintainable system while thinking about time and cost. I personally use an app called Spotify which is reliable and works well and updates with no down time, I find it quick and easy to find music and think the developers have done well with adding new features over time like AI DJ and mixes. On the other hand an app I find frustrating to use is Google Authenticator for college which feels awkward logging because using two different devices just feels weird, and if not using two different devices the code that you need is covered by the input pop up. I think the developers could improve this by getting feedback from users.
